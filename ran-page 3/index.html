（一）汇报人1：李XX（TiO₂掺杂改性研究）

  • 1. 汇报核心：以BaTiO₃为基体，掺杂3%、5%、8% TiO₂优化介电性能，初步得出5%掺杂比例介电常数最高的结论 【语音溯源：李XX 14:10-14:18】

（二）汇报人2：王XX（ZrO₂复合掺杂研究）

  • 2. 现存难点：复合掺杂后力学性能下降，作用机制缺乏理论支撑 【语音溯源：王XX 15:05-15:10】

当前实现方式

本地优先、OpenAI 兼容模型接口、可检查的多模态处理链路

7.1 本地应用与材料处理

  • ● Web 前端 + FastAPI： 统一承载材料上传、生成进度、纪要编辑、证据预览和资料库操作。
  • ● 本地存储： 组会记录、行动项和归档材料保存在本地 SQLite 与文件目录中；模型 Key 不进入仓库。

7.2 核心配置：从“生成”到“约束式生成”

  • ● 证据强制约束： 所有结论、反馈与行动项，必须引用输入素材中的证据（文献页码 / PPT 页码 / 转写时间戳），无证据不输出判断。
  • ● 结构化生成流： 系统先进行结构化抽取（讨论要点、反馈指令、术语实体），再进行段落级检索与对齐，最后生成结构化记录。

该策略确保在历史数据较少的冷启动阶段，仍能保持输出的可靠性与学术严谨性。

质量保障原则

以证据可检查、结果可编辑、失败可理解为当前版本的质量底线

8.1 持续验证指标

  • 素材导入准确率

    持续检查 PPT/PDF 页面渲染、文字提取与文件归属，避免材料缺页或来源错配。

  • AI记录生成质量

    通过官方案例和真实组会样本复核讨论要点、导师反馈与行动项是否完整、准确。

  • 溯源准确性

    每条证据保留来源、页码或位置；无法精确定位时明确显示整页回退，不伪造高亮。

  • 操作流畅性

    生成过程展示后端真实处理节点；长材料处理期间提供进度与明确的错误反馈。

8.2 纠错机制

✍️

用户手动纠错

生成后的纪要支持直接编辑、撤销和保存；行动项可在资料库中更新状态、期限与回应情况。

⚠️

明确错误与回退

模型鉴权、额度、文件解析或溯源定位失败时给出明确提示，并尽量保留已完成的处理结果。

🔄

模型可配置

通过 OpenAI 兼容接口切换模型服务；视觉页数和图像理解也可按材料规模调整。
